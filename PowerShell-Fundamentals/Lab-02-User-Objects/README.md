# Lab 02 - PowerShell User Objects

## Objective
Learn how to represent user identity information in PowerShell.

## What I Practiced
- Creating a PowerShell hashtable
- Storing user attributes
- Accessing object properties
- Working with Boolean values
- Displaying user information

## IAM Relevance
IAM systems work with identity attributes such as:
- Display name
- User principal name
- Department
- Job title
- Account status

PowerShell can be used to retrieve and automate these identity attributes.

## Example Output

Name: John Smith
Username: john.smith@contoso.com
Department: IT
Job Title: Help Desk Technician
Account Enabled: True
